FLIPNOOK LEGAL WEBSITE — HƯỚNG DẪN TRIỂN KHAI MIỄN PHÍ

Trong gói có:
- index.html: trang chính
- terms.html: Điều khoản sử dụng
- privacy.html: Chính sách quyền riêng tư

CÁCH NHANH, MIỄN PHÍ: GITHUB PAGES
1. Đăng nhập/tạo tài khoản tại https://github.com
2. Tạo repository mới, ví dụ flipnook-legal. Chọn Public.
3. Upload 3 file HTML vào thư mục gốc của repository và Commit changes.
4. Vào Settings > Pages.
5. Ở Build and deployment, chọn Deploy from a branch; Branch: main; Folder: /(root); Save.
6. Đợi GitHub Pages triển khai. Link sẽ có dạng:
   https://TEN-TAI-KHOAN.github.io/flipnook-legal/
   https://TEN-TAI-KHOAN.github.io/flipnook-legal/terms.html
   https://TEN-TAI-KHOAN.github.io/flipnook-legal/privacy.html

Dùng hai URL terms.html và privacy.html làm URL chính sách tạm thời trong Google Play Console nếu được chấp nhận theo yêu cầu hiện hành. Nếu muốn URL đúng dạng flipnook.app/terms và /privacy, cần quyền quản lý DNS/domain flipnook.app và cấu hình custom domain; không thể gắn domain đó nếu bạn không sở hữu/quản lý nó.
